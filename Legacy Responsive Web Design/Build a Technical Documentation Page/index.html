Variables

Variables are strings used to store data

There are different methods to create variables, based on what kind of information you want to store

    The most common words to create variables are:

  • Var
  • Const
  • Let

    Examples of variables are:

  • var name = office;
  • const block1 = users;
  • let cat = stewart;

Variables declared with the const word cannot be changed.

Variables declared with the word let can be changed latter.

Using the word var to declare a variable is outdated.

Variables should always be declared beforehand.

Using variables to store data is a great way to organize any block of code.

You can even assign functions to a variable.

    Example:

  • function sum(num1, num2)
    {return num1 + num2};
    const soma = sum(num1, num2);
Console.log Method

Console.log() is a method that prints any string or even the result of a function in the console.

You can use console.log all the time to check wether your variables are indeed assigned what you want.

In other words, console.log() is very useful for testing purposes.

console.log(string);

Loops

There are four types of loops in JavaScript:

  • Loop for

    for (expression 1; expression 2; expression 3)
    { // code block to be executed }

  • Loop for in

    for (key in object)
    { // code block to be executed }

  • Loop for of

    for (variable of iterable)
    { // code block to be executed }

  • Loop while

    while (condition)
    { // code block to be executed }

Loops are incredibly useful!
